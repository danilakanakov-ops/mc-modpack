# mc-modpack

Список модов Minecraft-сервера (NeoForge 1.21.1) в формате [packwiz](https://packwiz.infra.link/).

Этот репозиторий ведёт бот, руками его не правят: моды добавляют через Telegram-бота,
он сам коммитит сюда, когда сервер пуст. Сервер и игроки скачивают моды отсюда.

- `mods/*.pw.toml` — по файлу на мод: откуда качать и где он нужен (`side`)
- `jars/` — моды не с Modrinth/CurseForge, хранятся прямо здесь
